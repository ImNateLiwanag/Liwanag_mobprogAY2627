Lab Activity 0: discussion

As part of setting up my Flutter environment, I was able to learn how to configure and set up the environment necessary for working with Flutter using Visual Studio Code. The very first thing that I did was installing the Flutter extension and checking the environment using the flutter doctor command.

What I also learned during this activity is that simply installing the Flutter extension is not enough for Flutter development since Flutter depends on its SDK as well as other dependencies. As a part of setting up my development environment, I checked the Android toolchain and available devices for running my application. Once I created my Flutter project, I had an opportunity to explore its directory tree, specifically the lib directory and the main.dart file where the main part of the code resides.

This activity gave me an insight into the importance of preparing the development environment before working on a project. In the future activities, I will make sure to check my Flutter installation and update necessary dependencies before writing my code.
